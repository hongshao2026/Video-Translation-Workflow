# 广告检测、剪除与画面遮盖 SOP

## 1. 目标与执行顺序

每条新视频在冻结正式时间槽和开始翻译前，都必须检查两类广告：

1. **内容广告**：主持人口播赞助、整段推广、报名或优惠信息等，可考虑整段删除；
2. **画面广告**：二维码、网址、促销框、滚动条、角标、右下角广告组件等，通常保留节目内容但遮盖画面元素。

标准顺序：

```text
保留原始下载母版
→ 初步 ASR + 章节/画面抽帧/OCR 扫描
→ 形成广告候选清单
→ 根据证据自动决定 remove / mask / keep
→ 生成剪辑与遮盖计划
→ 制作独立工作母版
→ 对工作母版重新生成正式 ASR、时间槽和背景轨
→ ad_edit_gate=pass
→ 才能开始正式翻译
```

不得仅凭关键词自动删片。任何删除或遮盖都必须由 ASR 语义、章节结构、转场/停顿、画面/OCR 和候选区间前后文中的多项证据支持，并完整记录可追溯理由。不再逐项请求用户批准；未检测到广告时自动生成明确的 `no_ads_detected` 结论。

## 2. 检测要求

### 内容广告检测

结合以下证据定位候选区间：

- ASR 中的 sponsor、partner、discount、promo code、sign up、coaching program、website 等推广语义；
- 视频章节、简介链接和主持人口播结构；
- 进入广告和返回正片时的转场、停顿、音乐或固定话术；
- 候选区间前后至少各检查 10 秒，避免切掉正文的承接句。

### 画面广告检测

对全片定时抽帧，并在镜头变化、字幕条出现和固定角落元素变化处增加采样。至少检查：

- 四个角落，尤其右下角；
- 二维码、网址、价格、折扣码、报名按钮和赞助商 Logo；
- 只在部分时间出现的弹窗、横幅、下三分之一字幕条；
- 与节目永久台标的区别。永久节目 Logo 默认保留，除非用户明确要求遮盖。

每个候选必须记录开始/结束时间、截图证据、坐标、置信度和建议动作，不能只记录一句“有广告”。

## 3. 自动处置与剪辑原则

每个候选只能标记为：

- `remove`：整段删除；
- `mask`：保留节目内容，只遮盖指定画面区域；
- `keep`：证据不足、与正文难以安全切分，或属于节目本身识别元素时保留；不设置等待用户的 `needs_review` 状态。

自动决策规则：

- 只有在口播/赞助段语义完整、边界位于自然停顿或转场，且删除不破坏正文问答时才标记 `remove`；
- 节目正文必须保留、但画面中明确存在二维码、促销网址、价格/优惠框或赞助角标时标记 `mask`；
- 证据不足或边界不安全时一律 `keep`，同时在 QA 记录保留原因，禁止猜测性删除。

删除内容时：

- 在完整句子和自然转场处切入/切出；
- 视频、原声、背景轨、ASR、字幕和章节必须使用同一剪辑决定；
- 生成 `qa/source_to_edit_timeline.json`，记录每个原时间点到新时间点的映射；
- 原始下载母版永不覆盖，去广告工作母版使用新文件名；
- 自动分析或处置算法版本变化并改变删除决定后，所有依赖旧工作母版的翻译、TTS、字幕和章节时间都必须失效并重建。

## 4. 遮盖规则与字幕层级

遮盖计划至少记录：

- 生效时间区间；
- 像素坐标和归一化坐标；
- 遮盖方式（匹配背景、模糊、纯色块或经验证的图形）；
- 四周安全边距；
- 该区间的验证截图。

遮盖只在广告实际出现的时间内生效，并覆盖广告完整边缘及少量安全边距；不得遮挡人物面部、扑克桌关键信息或其他正文信息。如果广告区域与字幕区域相交，仍保持以下固定渲染顺序：

```text
底层：重定时后的视频画面
中层：广告遮盖、修补或覆盖图形
顶层：烧录中文字幕
独立轨：可开关中文字幕
```

因此字幕永远不能被广告遮盖框挡住。字幕样式、位置或时轴改变时，必须重新抽帧检查交叠区间。

## 5. 必须产出的文件

```text
qa/ad_detection.json
qa/ad_decisions.json
qa/ad_overlay_plan.json
qa/source_to_edit_timeline.json
qa/ad_edit_gate.json
source/<video_id>_original_master.mp4
source/<video_id>_edited_master_vN.mp4
```

如果没有剪除片段，`source_to_edit_timeline.json` 仍记录恒等映射；如果没有画面遮盖，`ad_overlay_plan.json` 仍以空列表落盘。这样“没有广告”是经过检查后的结论，而不是漏做。

## 6. `ad_edit_gate.json` 放行条件

只有下列条件全部满足，状态才能为 `pass`：

- 原始母版路径和 SHA-256 已记录且未覆盖；
- 全片内容广告与画面广告扫描均已完成；
- 每个候选都有基于证据的 `remove`、`mask` 或 `keep` 自动决定，并记录决策规则版本、置信度与理由；
- 存在原时轴到编辑时轴映射，连续、单调、无未解释缺口；
- 全部处置均由当前冻结的证据决策规则生成；若无广告则记录 `decision=no_ads_detected`；
- 工作母版、剪辑计划和遮盖计划的路径及 SHA-256 已记录；
- 正式 ASR、时间槽和背景轨基于正式工作母版生成；
- 计划的渲染顺序为“视频 → 遮盖 → 字幕”。

门禁缺失、非 `pass`、哈希不匹配或存在待决定候选时，禁止开始正式翻译。

## 7. 最终 QA

独立质检至少检查：

- 每个 `remove` 区间的前后边界各 10 秒，确认没有残留广告、跳音或切掉正文；
- 每个 `mask` 区间的开始、中间、结束和前后各一帧，确认遮盖没有提前出现或延迟消失；
- 遮盖区域完整覆盖广告，但未误盖人物或正文信息；
- 所有与字幕相交的区间中，字幕清晰位于最上层；
- 新章节和简介时间跳转均按编辑后时轴重新定位；
- 最终报告记录广告剪辑、遮盖计划和时间映射的 SHA-256。

任一项失败都必须回到广告计划或渲染阶段修复，不得把成片标记为完成。

## 8. 发布材料与封面的广告清理

成片广告处理通过不代表源标题、源简介或原封面天然适合中文发布。最终机器 QA 通过后还必须检查发布材料：

- 中文简介保留原视频链接、主题摘要和有内容价值的嘉宾介绍；删除课程/产品推广、优惠或跟踪链接、订阅引导、站点导流、无关标签、关键词堆砌，以及对白未实际提到却随源简介附带的书单或商品。
- 中文标题不得照搬促销式夸张承诺，也不得加入与内容无关的品牌、价格、收益或行动号召。
- 最终章节使用当前中文成片时轴；广告删除后的工作母版映射和视频重定时后的成片映射都必须纳入计算。章节跳转不得落入已删除区间，也不得沿用旧成片或原视频时间。
- 16:9 与 4:3 封面不得出现已决定删除/遮盖的广告内容、网址、二维码、优惠信息、订阅号召、广告角标或无关标签。节目永久 Logo 仅在用户有权使用且明确用于节目识别时允许保留。
- `qa/publication_materials_vN.json` 必须记录删除的推广类别和 `advertising_or_promotional_links_remaining=0`；`qa/cover_art_vN.json` 必须记录两张封面的广告残留检查为 0。
- `qa/publication_package_gate_vN.json` 必须绑定 `ad_edit_gate`、最终机器 QA、当前成片、最终章节、发布文案和封面 QA 的路径及 SHA-256。任一广告残留、哈希不匹配或章节映射错误都不得 `pass`。
