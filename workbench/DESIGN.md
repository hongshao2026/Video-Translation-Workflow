# 声轨工坊 Design System

## Overview

### Creative North Star

界面参照小型录音棚的分轨控制台与后期制作交接单：角色、音色、时间码和文件状态都有清楚位置，操作结果像音轨一样可以被逐句核对。视觉不模拟真实硬件，而是借用它的秩序、编号和状态语言。

### Product context and register

- **Audience and primary job:** 在 Windows 本机处理外语视频的中文创作者；从链接、角色和本地或 API 声音配置得到时间轴对齐的译配视频，并能看清自动任务、人工关卡和断点续跑位置。
- **Target market(s) and evidence:** 当前是用户自用的本地工作台，不假设公开市场或企业权限模型。
- **Locale(s) and language policy:** 产品界面为 `zh-CN`；模型名、文件扩展名和时间码保留英文技术写法。
- **Usage scene:** 桌面端长任务；信息密度中等，用户需要在生成前检查角色、文件齐全度和超时句。
- **Register:** 产品型工作台。表达集中在页首标题和时间轴交接组件，其余区域优先清楚和稳定。
- **Memorable signature:** 酸绿色时间码/序号标记、“任务包出去—音频包回来”的虚线交接桥，以及贯穿八阶段的生产轨。
- **Restraint:** 上传、检查表、错误信息和最终生成按钮保持熟悉的表单与表格结构，不用装饰性动画妨碍核对。
- **Anti-references:** 不做通用蓝紫渐变 SaaS 仪表盘，不做视频平台娱乐化卡片瀑布，也不把录音棚隐喻变成拟物旋钮。
- **Token ownership/runtime mapping:** 采用 Model B。`app/globals.css` 的 CSS 自定义属性是当前运行时来源；本文件镜像被接受的值并解释用法。组件直接消费这些语义变量，变更时同时更新两处并运行设计文档 lint。

## Colors

`primary` 是主要操作和本地可信状态，`accent` 只用于时间码、品牌标记和主操作中的小面积提示。`paper`、`card`、`line` 构成低对比的工作台层级；正文使用 `ink`，辅助信息使用 `muted`。`danger` 表示无法解码或上传失败，`warning` 表示音频超出原时间槽、可能与下一句重叠。键盘焦点使用 `focus`，不能只靠颜色传达状态。

当前仅提供明亮主题。强制高对比模式交还系统颜色；滚动条同时提供标准属性和 WebKit 回退。

## Typography

中文正文以 Arial 与 Microsoft YaHei 的现有运行时栈为准，14–16px 用于主要输入和说明，8–12px 仅用于紧凑的状态、标签与时间码。时间码、序号、数量和文件片段 ID 使用等宽 `utility` 字体。标题通过字号和紧凑字距建立层级，不依赖全大写英文；中文说明保持自然句式。

## Layout

新版资料库采用 Zotero 式三栏：左栏负责筛选与设置入口，中栏是项目资料库，右栏是当前项目检查器和八阶段生产轨；任务坞跨项目保持可见。桌面在 1440px 左右维持中等信息密度，窄屏将辅助栏折叠但不隐藏错误、门禁或恢复动作。兼容制作台仍按真实流程纵向展开。项目表、任务坞和证据编辑器各自拥有明确滚动所有权，长表单保持自然文档滚动；检查表在窄屏保留表格关系并显式横向滚动。

## Elevation & Depth

默认用背景色和 1px 边框分层。只有可选择的角色卡、模式选项和外部配音交接面板允许轻微阴影；静态检查表不使用浮层感。异步内容预留空间，进度和错误不会移动主要操作。

## Shapes

普通控件使用 8–11px 圆角，工作区卡片使用 14–18px 圆角；药丸形仅用于短状态。圆形只用于试听、连接点和简短状态标记。虚线边框仅表示文件投递或工作交接，不用于普通信息卡。

## Components

### Foundational visual states

所有可操作元素提供默认、悬停、`focus-visible`、按下、禁用和忙碌状态。成功使用绿色并配文字，警告使用琥珀色并说明影响，错误使用砖红色并给出修复路径。加载默认使用稳定尺寸的进度条或按钮忙碌文案，不使用骨架屏。

### Buttons and actions

主要安全操作使用 `primary` 实心按钮；次要操作使用白底描边；取消上传使用次要样式。按钮用明确动词，如“下载 ZIP”“上传并检查时间轴”“用外部配音生成试听”。忙碌时保持按钮尺寸并阻止重复提交。

### Navigation and data display

新版主视图使用资料库筛选、项目列表、检查器标签与任务坞组合；阶段状态只读取后端 SQLite 和门禁证据。设置页管理可替换的翻译/语音 Provider，项目运行创建后展示冻结快照。兼容制作台保留带 `aria-pressed` 的“制作台 / 全流程地图”导航。全流程地图由 `docs/workflow.definition.json` 提供阶段与人工关卡；逐句检查使用语义表格和粘性表头，不隐藏缺失或无效记录。

### Forms and overlays

产品表单由应用自行处理错误并设置 `noValidate`。搜索在非空时提供可聚焦的清除按钮。Provider、模型、音色和离散参数使用原生 `select`，明确接受操作系统拥有弹出菜单的几何与行为。API Key 默认遮罩，只发送到本机后端；默认写入操作系统密钥链，只有用户显式选择一次性内存后端时才随进程退出失效，任何情况下都不进入 URL、日志、项目文件或浏览器存储。文件上传同时提供可见选择按钮和拖放，客户端与服务端都校验类型、数量和大小；网络错误不清空用户已输入内容。

### Iconography

当前不引入图标库；只使用少量具有文字等价物的符号。符号作为辅助，关键操作始终保留中文标签和可访问名称。

### Motion

悬停和进度变化使用约 180–350ms 的状态过渡。动画只说明选择、投递或进度，不做循环装饰。`prefers-reduced-motion` 下移除位移并将持续时间降到近即时。

### Content and data visualization

文案从用户动作出发，直接说明“缺少哪句”“超出时间槽多少秒”“下一步做什么”。时间使用 `HH:MM:SS.mmm`，时长以秒显示两位小数，文件大小自动显示 KB/MB。一分钟原槽试听只裁句尾静音并保持自然语速，超时句以警告交给翻译校对或重新配音；正式全片同样禁止拉伸中文语音，改为完整保留原画面并对较长视频区块做平滑重定时，然后按新时间轴生成字幕。

## Do's and Don'ts

- **Do:** 让每个状态都能回到一个明确动作，例如补传、重配或生成。
- **Do:** 把角色名、片段 ID 和绝对时间贯穿任务包、上传检查与成片。
- **Do:** 明确区分“脚本已接入”“人工待确认”和“本次案例已完成”，不给静态说明伪装成实时后台状态。
- **Do:** 在付费语音调用前显示计费字符和人民币估值；锁定音色后的试听生成动作直接调用，用户的“生成全片/全文”指令直接授权当前冻结输入的全文调用，两者都不再叠加二次确认。
- **Don't:** 为了塞进时间槽而对中文配音做时间拉伸；一分钟试听保持原始起点并报告超时，正式全片通过平滑改变画面速度承接自然中文。
- **Don't:** 用一条完整中文音轨代替逐句文件后声称能够稳定自动对齐。
- **Don't:** 让警告、错误或进度只靠颜色表达，或在加载时移动主要按钮。
- **Don't:** 对结果可能已产生费用的超时请求自动重试，或把 API Key 写入项目文件。
